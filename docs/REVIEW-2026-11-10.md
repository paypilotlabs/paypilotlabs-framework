## 4. Naming options

**A) Metadata only (recommended).** Change: pyproject `[project.urls]` + `maintainers`; root `package.json` name → `paypilotlabs-framework` and its URLs; `ui/package.json` repository URL; the About-dialog label and source link (B7). Files touched: `pyproject.toml`, `package.json`, `ui/package.json` (+ `about.js` if B7 approved). Bench app name, imports, routes and asset paths stay `frappe`, so no product, apps.json or site changes. Risk: low.

**B) Full app rename to `paypilotlabs_framework`.** Not possible for this repo: the hard rules forbid renaming the `frappe` package, and bench requires the package, the pyproject name and `hooks.app_name` to match. It would touch every `.py` file in this repo (~4,000), every doctype JSON `module` path, `/assets/frappe/` in every template, every product's imports, every `docker/apps.json`, and every existing site's `apps.txt`. Listed only to rule it out.

**Recommendation: A**, plus bug fixes B1-B7.
